# Brew Log

ハンドドリップコーヒーの抽出条件と味を記録する、スマホ向けPWAです。

## 記録項目
- 日付（当日を初期値）
- 豆の種類
- 焙煎度：浅煎り / 中煎り / 中深煎り / 深煎り
- 豆量：15g / 20g / 30g / その他
- 湯温：75〜98℃
- 挽き目：TIMEMORE 15〜31クリック
- 抽出方法：4:6 / 7投式 / その他
- 味：甘み / 酸味 / 苦味 / 香り（各5段階）
- 総合評価：5段階
- メモ
- また飲みたい

## 履歴
データはブラウザの localStorage に保存します。履歴は豆名や「また飲みたい」で絞り込み、新しい順・古い順・豆名順で並び替えできます。絞り込みと並び替えは併用できます。各記録は編集・削除できます。

## 公開
GitHub Pagesなどの静的ホスティングでそのまま動作します。
